# FocusFlow – Full Stack Task Tracker

A modern full-stack productivity application built using Next.js, TypeScript, Prisma ORM, and PostgreSQL.

FocusFlow helps users manage daily tasks with a clean and responsive interface while demonstrating a complete production-style full-stack workflow.

## ✨ Features

- Add new tasks  
- Delete tasks  
- Mark tasks as completed/incomplete  
- Persistent database storage  
- Responsive and clean UI  
- Production-style API integration  
- Full CRUD functionality  
- Real-time frontend updates

## ⚙️ Setup Instructions

Clone the repository:

git clone https://github.com/YOUR_USERNAME/Focus-Flow.git  

cd Focus-Flow  

Install dependencies:

npm install  

Create .env file:

DATABASE_URL="your_postgresql_database_url"  

---

## 🧪 Prisma Setup

npx prisma generate  
npx prisma db push  

---

## ▶️ Run Project

npm run dev  

Open:
http://localhost:3000  

---

## 📡 API Endpoints

GET /api/tasks → Fetch all tasks  
POST /api/tasks → Create task  
PUT /api/tasks/[id] → Update task  
DELETE /api/tasks/[id] → Delete task
